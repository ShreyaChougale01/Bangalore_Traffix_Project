Bengaluru Traffic Flow Analysis and Congestion Management

Project Overview

This project analyzes Bengaluru traffic flow patterns to understand traffic volume, congestion levels, average speed, road capacity utilization, and travel-time indicators. It uses Python-based data analysis and an interactive Streamlit dashboard to present findings.

Project Objectives

- Analyze traffic volume and congestion patterns.
- Study relationships between traffic volume, speed, and congestion.
- Examine road capacity utilization and travel-time indicators.
- Identify areas and intersections with higher congestion.
- Present findings through an interactive dashboard.
- Explore illustrative traffic-reduction scenarios.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

Key Findings

- Average congestion level: 80.82
- Average recorded speed: 39.45
- Average travel-time index: 1.376
- Average road-capacity utilization: 92.03%
- Traffic volume and congestion show a strong positive correlation.

How to Run the Dashboard

1. Install the required libraries:
   
   "python -m pip install streamlit pandas plotly"

2. Run the dashboard:
   
   "python -m streamlit run Bengaluru_Traffic_Dashboard.py"

3. Open the local URL displayed in the terminal.

Dataset Limitations

The supplied dataset does not contain time-of-day, explicit road-type, or geospatial information. Therefore, findings describe the supplied dataset and should not be interpreted as measured peak-hour patterns or causal effects.
